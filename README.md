# Carlos Mamaril - Personal Website

Personal website for Carlos C. Mamaril Jr., a criminology student. Built with Astro, with a red and black journal design, photo album, and video.

## Run locally

```sh
npm install
npm run dev
```

## GitHub Pages

Push to main to build and deploy. In repository Settings > Pages, select GitHub Actions as the source.

Website: https://MacaraegIV.github.io/Mamaril-Website/
